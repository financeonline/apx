## 3. Running it locally again

```bash
cd /Users/shaukin/Desktop/MOTION
source ~/.motion-runtime/env.sh          # puts docker / node / supabase on PATH
npx supabase start                        # local database (data was kept)
npm run build
nohup npm run start -- --port 3000 > /tmp/motion-app.log 2>&1 &
# Job loop (reports, recalculation, purge…): uses CRON_SECRET from .env.local
CRON_SECRET=$(grep '^CRON_SECRET=' .env.local | cut -d= -f2-) \
  bash -c 'while true; do curl -s -o /dev/null -H "authorization: Bearer $CRON_SECRET" http://127.0.0.1:3000/api/jobs/run; sleep 15; done' &
```
Open http://localhost:3000.

Useful fixes:
- If `next start` says port 3000 is in use, kill the old `next-server` first (`pkill -f next-server`). A failed restart silently leaves the OLD build running.
- Auth container out of connections → `docker restart supabase_auth_MOTION`.
- Database shell: `docker exec -i supabase_db_MOTION psql -U postgres -d postgres`.
- A migration applied by hand must also be recorded: `insert into supabase_migrations.schema_migrations(version,name) values (...)`.

## 4. What was built in this stretch (ADR-151 → ADR-168)

### Design (ADR-151 – 155)
- shadcn/ui interface; the owner's violet reference design on every page; white cards, sidebar with the ChatGPT-generated logo and leaf artwork; slogan "Smarter finance, brighter possibilities."
- Departments hub: compact rectangular cards, whole card clickable, edges glow on hover; statuses from real data only.
- Home headline cards in the widget-grid design (no dragging).
- Sidebar foot shows the signed-in person (name, role) above Sign out on every shell.

### Finance features (ADR-156)
- Loans marked **secured / unsecured** per account; **fixed and current assets**; Balance sheet page.
- **VAT return** (UK nine boxes, UAE VAT201) by quarter; **Corporation Tax** indicative estimate (UK 19/25% with marginal relief; UAE 9% over AED 375k).
- **Currency and country** per company (UK/UAE/IE/IN; currency only while the company has no records).
- Custom report areas: Loans, Assets, VAT, Corporation Tax.

### Super admin panel (ADR-157 – 160, 166 – 168)
- **One super admin** (enforced in the database). Only the super admin adds staff (staff only) and creates companies.
- **Systems per company**: the super admin switches Banking, Customers, Actions, Reports, AI Analyst, Planning, Tax, Funding Readiness and AI document reading on or off; a switched-off system disappears (404, hidden tabs, AI tools withheld).
- **Organisations list**: search; Activate / Deactivate; **Edit** (name, legal name, country, currency, financial year, plan, and the **owner's sign-in email and password**); **Delete** asks "Are you sure?" and schedules erasure in 30 days (Restore until then); **Delete now** asks "Are you sure you want to delete it permanently?" and erases at once.
- **Create a company**: optional owner password (owner can sign in straight away), otherwise an invitation link. Fixed: invitations sent by the super admin are now accepted.
- **Confirm it is you** bar on platform pages: sensitive changes need the super admin's password from the last 10 minutes.

### Sign-in (ADR-159, 161, 164)
- **Two-step sign-in removed completely** (database rule, setup page, column, setting). Password sign-in only.
- Sign-in page: "Create an account" and "Forgot your password?" links removed (the pages still exist by URL; the home page still links to sign-up).

### AI (ADR-157, 162 – 165)
- Keys managed on the super admin's **Account** page, stored encrypted in Supabase Vault, checked with the provider before saving.
- **Anthropic** (card "AI provider key") and **OpenAI** (card "OpenAI key"): exactly **one is Active**; "Make active" switches and the other becomes Inactive. Removing the OpenAI key while it is active falls back to Anthropic.
- Each card has its own **model** and **effort** drop-downs; a choice is proven with a small test call before it is stored.
- Default model: **Claude Haiku 4.5** (`claude-haiku-4-5-20251001`). Haiku has no effort setting; Sonnet 4.6 / Opus 4 do; OpenAI effort only on o-series / GPT-5.
- The Claude 5 family (Sonnet 5.5, Opus 5.5…) is **refused**: it does not support the required tool call MOTION's answers depend on.
- Grounding fix: a "not covered" note may name a period ("Jun 2026"); a rejected answer now says "didn't pass MOTION's checks" instead of "unavailable".

### Account page
- Two columns: Your details + OpenAI key on the left, AI provider key on the right. Time zone is a drop-down with offsets.

3. **Rotate the Anthropic key** — it was pasted in chat. Create a new key at console.anthropic.com and save it on Account.
4. **OpenAI** has not been tried with a real key; check one answer end to end once a key exists. Grounding was tuned on Claude.
5. **Hosting**: choose the production Supabase project and app host; apply migrations in order; set env (`NEXT_PUBLIC_SUPABASE_URL`, anon key, service key, `SUPABASE_JWT_SECRET`, `CRON_SECRET`, optional `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `ANTHROPIC_MODEL`); a scheduler to call `/api/jobs/run`; enable TOTP only if two-step returns.

8. Docs still mention the old two-step rules in historical files (ADR-161 supersedes them); `docs/PHASE_16_*` references to `OrgFeatureToggle` could be updated.
